# Corona Asesor

AI agent that plans and quotes floor and wall tile installations (tiles, adhesive and grout) on top of the public Corona Colombia catalog, with every number backed by a tool call over real data.

**Status:** rewrite in progress. Design document: [docs/design/2026-10-01-portfolio-rewrite-design.md](docs/design/2026-10-01-portfolio-rewrite-design.md).

Academic exercise originally built for the AgentSprint by ReshapeX competition. Built only from publicly available information. Not affiliated with or endorsed by Organización Corona; the Corona brand, logo, catalog data, technical sheets and product images belong to Organización Corona.
